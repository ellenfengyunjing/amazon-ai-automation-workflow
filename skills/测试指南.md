# nfwl 首批 Skills 测试指南

本批只有三套业务能力：卖点、Listing、组图，共十个Skill目录。源码在本目录，Codex和WorkBuddy使用安装副本。没有开发SKU管理、样品验收、说明书、选品、视频、后端或前端。

## 直接测试

在宿主中使用以下入口。若当前聊天尚未显示新入口，可明确要求Agent读取已安装目录中的SKILL.md并执行。无需先启动网页或后端。

### 卖点

```text
使用 $nfwl-selling-points。读取该Skill的 examples/selling_sauce.json，生成英文卖点和中文审阅解释，输出JSON、HTML和缺项清单。不要把待复核的容量、温度单位或水位冲突写成确认事实。结果放在一个新的测试目录。
```

也可以直接提供你自己的产品资料，不必手工先写JSON。Agent会按输入契约整理来源和事实。

### Listing

```text
使用 $nfwl-listing。读取该Skill的 examples/listing_multilingual.json，输出英文/美国站和德文/德国站，分别生成organization与access两套策略，共四条Listing。研究数据缺失时明确标为市场未验证，不编流量；输出HTML、结构化列表和质检。产品是合成测试样本，不是真实商品。
```

要测试真实数据，把自己的ASIN、关键词或卖家精灵/Sif导出文件交给Agent。宿主能发现真实MCP工具时使用；没有连接时不读取其他Skill中的密钥，不替你改配置。

### 组图

```text
使用 $nfwl-image-suite。读取该Skill的 examples/images_sauce.json，参考同目录reference.png。使用宿主内置生图，只生成资料足够的白底图和A+细节图；缺尺寸的图位保持阻塞。保留原生图，按交付尺寸等比例导出，查看图片并输出逐图质检。全部产物使用新目录。
```

局部返工：

```text
继续刚才的nfwl组图任务，只修改main01指定问题。使用原图和本品参考，保留其他图位与旧版本，输出新版本并记录parent_asset。
```

样例照片来自用户提供的说明书封面，包含产品与额外排版元素，仅用于当前项目验证。正式商品图请换高清本品实拍；不能把生成图当作新的产品事实来源。

## 结果与限制

- 卖点JSON可供后端生成列表；Listing按SKU×站点×语种×策略输出；图片按图位/语言/revision输出。
- 脚本完成的是可重复机械检查，不是万能语义审查。独立语义观察及人工确认分别保留。
- 合成产品或关键词测试数据明确标为synthetic/test_fixture；没有实时采集就不记live。
- 产品确认事实与买家/VOC证据分开。不同语种不得改参数或编本地流量。
- 图片生成和内容修改由宿主图像工具完成；尺寸导出只等比例缩放/补白，不重绘、不裁切、不拉伸产品。原生与交付像素分别记录。
- Codex与WorkBuddy的工具权限不同。安装和脚本可验证，WorkBuddy里的真实Agent/生图调用仍须在该宿主实际运行，不把文件复制成功称为端到端通过。

## 配套脚本

核心脚本使用Python 3.10+标准库；图片文件检查需要Pillow。画布导出需要Node.js与sharp。宿主有工作区依赖加载器时使用其返回的运行时，不改项目package.json、不安装到旧Skill。

```text
python <主Skill目录>/scripts/nfwl.py prepare --input input.json --output context.json
python <主Skill目录>/scripts/nfwl.py validate --input input.json --result result.json --output qa.json
python <nfwl-listing目录>/scripts/nfwl.py strategy --input input.json --output strategy.json
python <主Skill目录>/scripts/nfwl.py report --input input.json --result result.json --output report.html
```

所有输出使用排他创建，文件已存在就停止；选新修订目录或新文件名。脚本不会通过LLM自动写文案，创作按SKILL.md由当前Agent执行。

## 源码开发与安装

- `_shared/`是核心校验/契约源码，tools/build_package.py同步到三套主Skill，安装后不依赖项目的_shared路径。
- tools/create_test_samples.py仅初次创建明确标签样本；tools/run_smoke.py重放当前Agent编写的样例，不是通用文案生成器。
- tools/install_skills.py默认预检两个宿主的全部目标；加--apply才复制。任何同名目录存在就停止，不能用此工具更新覆盖已有目录。
- 仅安装manifest中的十个新Skill，不写MCP配置、别名、PATH或其他项目配置。
- tests/test_nfwl.py是业务回归测试；测试报告另外记录实际工具运行与未验证项。
