# Amazon AI 自动化工作流 · 交互演示工作台

跨境电商（亚马逊新品上架）全流程 AI 自动化工作台的**纯前端交互演示**（单 HTML 文件，无外链依赖，可直接双击打开）。

## 项目结构

```
├── 小清跨境_工作台交互演示.html   # 主交付物：单文件交互演示（当前 v13）
├── 小清跨境AI自动化工作台_方案v1.md # 技术方案文档（17 章）
├── CHANGELOG.md                  # 版本修改记录（每次更新必写）
└── README.md
```

## 工作流总览

**10 个模块**（依赖图驱动，非线性流水线）：

```
商品中心：选品调研（深度可视化报告）→ 商品池（统计 + 7 环节进度）
新品管理：① 样品验收（含 12 项必备资料补齐）
         ② 卖点生成（多语种 · 提示词可自定义）
         ③ Listing 文案（埋词分析 → 策略 → 文案确认）
         ④ 说明书（多语种 PDF）
         ⑤ 图片需求表（语种 × 图片类型）
         ⑥ AI 批量生图（工作台 + 图片库双 Tab）
         ⑦ 上架（亚马逊新品上架表 · 导出 Excel · 预留领星一键上架）
系统：设置（管理员 / 员工双角色）
```

核心特性：

- **数据流转**：商品池「确认选品」→ 验收「审核通过」→ AI 自动批量生成卖点 / Listing / 说明书 / 图片需求 → 人工逐环节审核 → 上架汇总
- **AI 深度分析可视化**：选品调研 10+ 图表报告；Listing 关键词流量 / 埋词策略 / 竞品对比
- **交互模式**：右侧详情抽屉、飞书多维表格风单元格（语种/图片类型下拉多选）、勾选后底部浮动批量操作栏、分页、横向滚动宽表
- **人工介入**：每个 AI 生成环节均有重新生成（支持修改指令）/ 人工修改 / 审核通过

## 版本管理约定

- 每次更新界面或功能，必须：
  1. 修改 `小清跨境_工作台交互演示.html`
  2. 在 `CHANGELOG.md` 顶部追加该版本改动摘要
  3. `git add` + `git commit -m "vXX: 一句话说明"`
  4. `git push origin main`

## 技术说明

- 纯原生 HTML/CSS/JS 单文件（约 155KB），零依赖、零构建，浏览器直接打开
- 状态机：`S` 全局状态 + 模块依赖图 `MODS/DEP`，演示数据内置
- 回归测试：Playwright-core 脚本（本地 `_reg_v13.js`，65/65 全绿，不入库）
